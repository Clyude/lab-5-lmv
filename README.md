# Лабораторна робота №5 — мобільна версія сайту

Сайт адаптований під мобільні розміри:
- Extra Small: менше 576px
- Small: від 576px

Основні зміни:
- додано окремі media-запити для мобільної версії;
- прибрано ризик горизонтальної прокрутки;
- зменшено великі заголовки та блоки;
- зроблено кнопки й посилання зручними для натискання;
- форма стала коротшою, додано autocomplete;
- телефон залишено активним через tel:;
- замість alert використано повідомлення під формою.
